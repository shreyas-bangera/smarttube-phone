Sign in & privacy

Your password never touches StreamTube

Signing in works exactly like a smart TV: the app shows a short code, you approve it on Google's own website. That's it.

  1. You tab → Sign in
  2. Get the code
  3. Approve at yt.be/activate
  4. Signed in, automatically
  • It keeps only the access token Google gives it — on your phone.
  • It talks to YouTube, GitHub (updates) and SponsorBlock if enabled.

Install

Three steps.
Sixty seconds.

No Play Store, no account required to watch. Android 8.0+ on an ARM phone.

1

Pick your APK

arm64 for almost every phone since 2017. Not sure? Grab the universal one — the in-app updater picks the right build next time.

arm64Recommended · most phones ↓ APK arm32Older or budget 32-bit phones ↓ APK universalAny device, emulators, Chromebooks ↓ APK
2

Allow the install

Tap the finished download, then let your browser install apps when Android asks — Settings → Allow from this source.

If Play Protect warns about an unknown app, tap More details → Install anyway. Every build is made and signed by GitHub Actions from this public repository.

3

Open & watch

Home shows popular videos straight away — sign in only if you want your subscriptions, playlists and comments.

Allow notifications when asked; they're used for background-play controls and update news.

Already have it? Updates install from inside the app (You → Settings → Check for updates), or grab the latest APK above and install it over the old one — your settings stay. On builds 39–51 install the latest APK manually once; from build 38 or older, uninstall once first.
FAQ

Good to know

Is StreamTube really free and open source?

Yes — MIT licensed, source public, builds signed by GitHub Actions. It's an independent project: not affiliated with SmartTube's developer, YouTube or Google.

Play Protect says “Harmful app blocked”. Now what?

Play Protect sometimes flags open-source apps installed outside the Play Store. Tap More details → Install anyway. The code and build pipeline are public in this repository.

I get “App not installed” when updating

On builds 39–51: install the latest APK manually once — it installs over your app and keeps your settings. From build 38 or older: those used a temporary signing key, so uninstall once, then install the latest APK. Every update after that is normal.

The sign-in code doesn't appear

Check your connection and turn off Private DNS, ad-blocking DNS or VPN apps that block YouTube or Google, then tap Try again.

“Sign in to confirm you're not a bot”

YouTube sometimes asks this on shared or busy networks and with VPNs. Signing in usually fixes it; switching between Wi-Fi and mobile data can help too.

Videos buffer a lot

Open the player settings and pick a lower quality (1080p is the default on phones), or turn off high frame rate.

No sound in the background, no lock-screen controls

Turn on notifications (You → Settings → Notifications) and set StreamTube's battery usage to Unrestricted — on OnePlus, Xiaomi, Samsung and similar phones.
